1. 適用範圍

裕晶醫學科技股份有限公司（以下稱「本公司」）提供 YuGuard Drive Backup（以下稱「本服務」），供已開通服務的合作機構及獲授權操作人員備份 YuGuard 快篩 PDF 報告。本政策適用於使用本服務時的報告傳送、Google Drive 授權、雲端保存及相關資料處理。

本政策針對報告備份功能，並非 YuGuard App 所有其他功能的完整資料處理說明。其他功能及合作平台的資料處理，應併同閱讀其適用的隱私權政策與服務說明。

2. 我們處理哪些資料

  • 登入與授權資料：操作帳號識別碼、電子郵件、顯示名稱、登入驗證資訊及使用權限，用於確認是否可使用備份服務及量測所屬帳號。
  • 快篩 PDF 與量測資訊：量測日期、心電圖、心率、分析結果與比率，以及報告中實際包含的姓名、床號、住民資訊或手動備註。報告內容可能包含可識別個人的健康資料。
  • 備份紀錄：報告識別碼、檔名、量測時間、操作帳號、雲端檔案與資料夾識別碼、內容檢核值及上傳狀態，用於查找、確認完成情形及避免重複備份。
  • Google 授權資料：管理者授予本服務的存取憑證、更新憑證，以及獲授權資料夾或檔案的名稱、識別碼與權限資訊。本服務不取得管理者的 Google 密碼。
  • 服務與申請紀錄：必要的請求時間、錯誤或安全紀錄，以及使用者聯絡客服時主動提供的資訊。

操作人員應在具備適當權限並完成必要告知或同意的情況下上傳他人資料，且避免在備註中填寫與報告用途無關的個人資訊。

3. 資料使用目的

我們將上述資料用於驗證使用資格、保存與查找報告、確認上傳結果、處理故障及安全事件，以及回應資料存取或刪除申請。本服務不將報告或透過 Google API 取得的使用者資料出售，亦不將其用於廣告投放或訓練通用人工智慧模型。

本服務對 Google API 所取得資料的使用與移轉，遵守 Google API Services User Data Policy，包括適用的 Limited Use 要求。

4. Google Drive 授權如何使用

本服務由指定雲端硬碟的帳號管理者完成 Google OAuth 授權，使用 https://www.googleapis.com/auth/drive.file 範圍，存取管理者選取或本服務建立的相關檔案與資料夾。

實際用途包括確認指定備份資料夾、建立量測日期資料夾、上傳 PDF，以及核對檔案資訊及存取權限。本服務不以此授權掃描或處理雲端硬碟中其他無關檔案。

授權憑證保存在後端的密鑰管理服務，供備份服務取得短效存取憑證使用。一般 App 操作人員沿用既有登入方式，不需為每次備份登入 Google。

管理者可前往 Google 帳戶的第三方連結管理頁面撤銷本服務授權。撤銷後，本服務將無法繼續以該授權存取雲端硬碟；撤銷授權本身不會刪除先前已保存的報告。

5. 報告保存位置與分享對象

PDF 由本服務傳送並保存至公司指定 Google 帳號所管理的雲端硬碟備份資料夾，依機構及量測日期整理。相關備份紀錄另保存於後端資料庫，PDF 不會放在本服務介紹網站的公開空間。

上傳時不會自動將檔案設成「知道連結的任何人」可存取。檔案仍會受到所在資料夾與檔案既有權限的影響；公司管理者及經授權的檢視者可在其權限範圍內存取。

需要提供合作單位報告時，由管理者確認用途、對象及範圍，再分享個別檔案或日期資料夾。取得檔案的對象可能下載副本，其後續處理應遵守適用的授權與資料保護要求。

與 Jubo 的資料傳送

對於選擇 Jubo 住民的量測，YuGuard App 會依整合功能傳送住民識別碼、量測時間、量測結果、比率及報告檔名至 Jubo。此流程不透過 Jubo API 上傳 PDF，也不自動提供公開下載網址。只有手動備註、未選住民的 Jubo 報告，僅備份 PDF，不傳送 Jubo 量測 API。

Jubo 收到的資料及經分享取得的報告，亦受該合作單位自身的資料處理規範約束。刪除本公司的備份，不會自動刪除 Jubo 或其他接收者已取得的資料或副本。

6. 保存期間與刪除

目前不設定快篩 PDF 的自動到期刪除期限。公司依服務及業務需要人工檢視、清理報告，並受理資料當事人或獲授權機構提出的刪除申請。

收到申請後，本公司會確認申請人身分、授權及資料範圍，處理相關報告與備份紀錄的刪除或其他適當措施。若仍有必要保存的法律、契約或爭議處理需求，將向申請人說明處理情形。Google 雲端硬碟的垃圾桶及平台備份，依其適用機制處理；刪除申請會一併評估永久刪除需求。

停用服務或撤銷 Google 授權，不等同刪除已保存的檔案。若希望刪除，請另外向本公司提出申請，或由具備權限的管理者處理。授權憑證與維運紀錄依服務需求及適用保存要求管理，不因 PDF 的人工保存方式而承諾永久留存。

7. 資料安全與服務供應商

本服務採用加密連線傳送報告，於備份前確認登入及使用權限，並以後端存取控制、密鑰管理及雲端硬碟權限限制資料存取。僅獲授權人員因維運、客服或經核准的報告提供需求，得在必要範圍內處理資料。

本服務使用 Google Firebase、Google Cloud 及 Google Drive，支援登入驗證、後端處理、備份紀錄、憑證管理及檔案保存。這些供應商會依其服務條款與資料保護安排處理必要資料；依實際服務配置，處理地點可能位於使用者所在國家或地區以外。

本公司會採取合理的保護措施，但任何網路傳輸或儲存系統均無法保證完全沒有風險。若有影響本服務的資料安全事件，將依事件情形與適用要求處理及通知。

8. 資料申請與聯絡方式

如欲查詢、更正、取得資料副本、停止相關處理或申請刪除，請聯絡本公司，或透過提供量測服務的機構協助提出。我們可能要求必要的身分或授權證明，以避免將資料提供給無權取得的人。

初次聯絡時，請提供聯絡方式及可協助查找的量測日期或檔名；不必直接寄送完整健康報告、密碼或授權憑證。若需要其他資訊，我們會另行說明提供方式。

9. 本說明網站的瀏覽資料

本服務介紹與政策網頁使用 GitHub Pages 提供靜態網頁。本網頁未加入廣告追蹤或流量分析程式，也不提供健康報告上傳表單。網站託管供應商可能依其安全及維運需求處理 IP 位址、請求時間或瀏覽器等技術資訊，詳見 GitHub 隱私權聲明。

前往 Google、Yutech 官網或其他外部連結後，該網站的資料處理依其各自的政策辦理。

10. 政策更新

本政策可能隨服務功能、資料處理方式或適用要求調整，更新時會於本頁標示日期。若新增資料用途或擴大 Google 資料存取範圍，將在適用情況下另行告知並取得所需同意或授權。
